# Recipe Unlocks

Серверный мод для NeoForge (Minecraft 26.2): рецепты закрыты, пока игрок их не откроет.

- Рецепты закрыты для каждого игрока, пока он их не откроет.
- Предмет с правилом в конфиге открывается только выполнением этого правила. Остальные рецепты открываются как в обычной игре (книга рецептов).
- Можно закрыть всё или только предметы, для которых записаны правила.
- Пока рецепт закрыт, предмет нельзя скрафтить даже при наличии ингредиентов. Использовать готовые предметы можно.
- Мод ставится только на сервер. Игрокам нужен обычный клиент NeoForge той же версии, без этого мода.

## Установка

1. Собрать мод (см. «Сборка») или взять готовый `recipe_unlocks-<версия>.jar`.
2. Положить jar в папку `mods` сервера NeoForge 26.2.
3. Запустить сервер. Появится файл `config/recipe-unlocks.toml` с подсказками внутри.

При установке на живой сервер уже открытые рецепты у игроков остаются. Чтобы откатиться, достаточно убрать jar.

## Конфиг

```toml
# Режим 1: закрыты все рецепты; открываются как в обычной игре.
lock_all_recipes = true
# Режим 2: действуют правила ниже; предмет с правилом открывается только правилом.
template_unlocks = true

[unlocks]
torch = break stone 3 & (eat apple | drop stick)
furnace = break #minecraft:base_stone_overworld 20
bow = hit skeleton 2 и pickup string 3
"#minecraft:planks" = jump #minecraft:logs 5
create:cogwheel = place #minecraft:logs 10 | stat sleep_in_bed
```

| `lock_all_recipes` | `template_unlocks` | Что закрыто | Как открывается |
|---|---|---|---|
| true | true | все рецепты | предмет с правилом — только правилом; остальное — как в обычной игре |
| true | false | все рецепты | как в обычной игре; правила не действуют |
| false | true | только предметы с правилами | только правилом |
| false | false | ничего | — |

Рецепт, который игрок открыл до появления правила, у него остаётся. Если правило удалить, рецепт, который игра уже должна была выдать, выдаётся сразу.

После правки файла: `/unlocks reload`. Перезапуск сервера не нужен. Ошибки показываются в ответе команды и в логе сервера с номером строки; строка с ошибкой пропускается, остальные работают.

Кавычки вокруг названия и правила можно не писать. На один предмет — одно правило; несколько условий соединяются через `&` и `|`. Комментарий начинается с `#` и пробела.

### Правило

`что открыть = что сделать`

**Что открыть**

| Запись | Что откроется |
|---|---|
| `torch`, `minecraft:torch`, `create:cogwheel` | все рецепты, которые дают этот предмет |
| `"#minecraft:planks"` | рецепты всех предметов из тега (тег пишется в кавычках) |
| `minecraft:iron_ingot_from_blasting_raw_iron` | один рецепт по его id |

Id предмета виден в игре: F3+H, затем навести курсор на предмет. `minecraft:` можно не писать.

**Что сделать**: шаблон, цель и количество. Без количества — 1 раз.

| Шаблон | Что считается | Цель |
|---|---|---|
| `break` | сломать блок | блок |
| `place` | поставить блок | блок |
| `jump` | прыгнуть, стоя на блоке | блок |
| `hit` | ударить существо (удар должен нанести урон) | существо |
| `kill` | убить существо | существо |
| `eat` | съесть или выпить | предмет |
| `pickup` | подобрать с земли | предмет |
| `drop` | выбросить | предмет |
| `use` | применить (правая кнопка) | предмет |
| `craft` | скрафтить, переплавить или купить у жителя | предмет |
| `stat` | любая статистика игры: `stat jump 100`, `stat sleep_in_bed` | id счётчика |

Шаблоном может быть и любой тип статистики из игры или модов (`mined`, `killed_by`, `broken`, …): мод берёт их из реестра игры.

**Цель**: id (`stone`, `create:cogwheel`), тег (`#minecraft:logs`) или `*` — что угодно. Блок можно писать по id предмета: `break torch` засчитает и факел на стене.

**Несколько условий**: `&` — «и», `|` — «или», скобки группируют. Вместо `&` можно писать `и`, вместо `|` — `или`. Без скобок `&` сильнее `|`.

Правила счёта:

- прогресс у каждого игрока свой и сохраняется вместе с миром;
- считается только то, что сделано после появления правила: накопленная раньше статистика не учитывается;
- творческий режим не засчитывается;
- удары по игрокам и убийства игроков не считаются.

### Дополнительные настройки

| Настройка | По умолчанию | Что делает |
|---|---|---|
| `lock_recipes_without_unlock` | `false` | Только для режима 1. Рецепты, которые нельзя открыть никак (игра их не открывает и в `[unlocks]` их нет; обычно это рецепты станков из модов): `false` — оставить доступными, `true` — закрыть навсегда. |
| `lock_crafter` | `true` | Автокрафтер собирает только то, что открыл поставивший его игрок, и только пока этот игрок в сети. |
| `block_modded_stations` | `true` | Скрывать закрытые рецепты от станков из других модов, когда ими пользуется игрок. |

## Команды

Для операторов (уровень gamemaster):

| Команда | Что делает |
|---|---|
| `/unlocks reload` | перечитать конфиг и показать замечания |
| `/unlocks progress <игрок>` | показать прогресс игрока по каждому правилу |
| `/unlocks reset <игрок>` | обнулить счётчики игрока и закрыть обратно рецепты, выданные правилами (рецепты, открытые обычным путём, остаются) |

Ванильная `/recipe give` выдаёт любой рецепт, в том числе с правилом: это решение оператора.

## Что блокируется

| Где | Как |
|---|---|
| Верстак и сетка в инвентаре | закрытый рецепт не даёт результата |
| Кузнечный стол | закрытый рецепт не даёт результата |
| Камнерез | закрытый вариант не выбирается |
| Печь, плавильня, коптильня | игрок не может положить сырьё, для которого у него нет открытого рецепта, и не может забрать результат закрытого рецепта |
| Костёр | игрок не может положить еду с закрытым рецептом |
| Автокрафтер | см. `lock_crafter` |
| Станки из других модов | если станок ищет рецепт обычным способом игры в момент действия игрока, закрытый рецепт он не найдёт |

Чего мод не закрывает:

- автоматику: печь, которую загружают и разгружают воронки или выбрасыватели, работает без ограничений;
- содержимое сломанной печи: оно выпадает как обычно (положить туда сырьё закрытого рецепта руками игрок не может);
- станки из модов, которые подбирают рецепт сами, без участия игрока;
- особые рецепты без записи в книге рецептов (фейерверки, копирование карт, покраска брони): игра сама никогда их не блокирует;
- творческий режим.

## Сборка

Нужен JDK 25.

```sh
./gradlew build               # jar появится в build/libs
./gradlew runGameTestServer   # игровые тесты на настоящем сервере без окна
./gradlew runServer           # тестовый сервер с модом в папке run/
./gradlew runCleanClient -PjoinServer=127.0.0.1:25565   # клиент без мода, сразу заходит на сервер
```

Игровые тесты лежат в `src/gametest` и в собранный jar не попадают.
