# Recipe Unlocks

Серверный мод для NeoForge (Minecraft 26.2): рецепты закрыты, пока игрок их не откроет.

Статус: проектирование, кода пока нет.

## Идея

- Все рецепты изначально закрыты для каждого игрока.
- Рецепт открывается ванильно (книга рецептов) или выполнением условий из конфига.
- Блокируется крафт, а не использование предметов.
- Мод нужен только на сервере. Предметы задаются по id, теги поддерживаются, поэтому он работает с рецептами других модов без хардкода.

## Конфиг (черновик)

```toml
lock_all_recipes = true   # режим 1: всё закрыто, открытие как в ванилле
template_unlocks = true   # режим 2: плюс открытие по условиям ниже

[unlocks]
"minecraft:torch"   = "break stone 3 & (eat apple | drop torch)"
"minecraft:furnace" = "break #minecraft:base_stone_overworld 20"
```

- Условие записывается как `шаблон цель [количество]`.
- Условия объединяются через `&` (И), `|` (ИЛИ) и скобки.
- Шаблоны: `break`, `place`, `jump`, `hit`, `kill`, `pickup`, `drop`, `use`, `eat`.
